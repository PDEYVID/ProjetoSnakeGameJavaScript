# Snake Game

Este é um simples jogo da cobrinha (Snake) desenvolvido em JavaScript, HTML e CSS.

## Como jogar

- Use as setas do teclado para mover a cobrinha.
- Coma a comida azul para crescer.
- Não bata nas paredes nem em si mesmo, ou o jogo acaba.

## Estrutura do projeto

- [`index.html`](index.html): Estrutura da página e canvas do jogo.
- [`style.css`](style.css): Estilos para centralizar e colorir a página.
- [`script.js`](script.js): Lógica do jogo, movimentação e regras.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo [`index.html`](index.html) em seu navegador.

## Créditos

Desenvolvido para fins de estudo e prática de JavaScript.
